## Projects
- **This portfolio's AI chat** — This site includes an AI chat (the one you're using right now) that answers recruiter questions grounded strictly in this profile content — no fabricated answers. Built with Next.js API routes, Vercel AI SDK (`ai`, `@ai-sdk/react`), and OpenRouter, running an open-source model (`openai/gpt-oss-20b:free`) via an OpenAI-compatible endpoint. The system prompt loads this markdown file directly at request time and instructs the model to answer only from it and decline unrelated questions. A live, working example of the applied-AI/LLM-integration work described above, not just a claim on a resume.
- **Picselectr** — A photo selection tool for photographers. Clients get a unique, PIN-protected link (`/select/[slug]`) to browse their event photos and choose which ones they want delivered across three tiers: digital files, album prints, and album cover (exactly 2 photos). Selections cascade — removing a photo from digital automatically removes it from album and cover. Includes an admin dashboard (`/events`) for creating events (wedding, birthday, quinceañera, photobooth, etc.), uploading photos, tracking client selections, setting deadlines, and sharing links. Stack: Next.js (App Router), Supabase (auth, database, RLS), Cloudflare R2 (photo storage), Tailwind CSS, TypeScript, pnpm. In active use by a real photography studio with real clients, cutting the photo-selection process from weeks down to days. No AI yet — currently working on adding it.
